# 공통 개발 기준 (CLAUDE.md·AGENTS.md가 참조하는 원본)

## 범위
DART OpenAPI 중계 전용입니다. 다른 업스트림이나 기능을 추가하지 않습니다.

## 불변 조건
- 업스트림 호스트는 `src/dart.js`의 `opendart.fss.or.kr`로 고정합니다. 요청으로 URL이나 호스트를 바꿀 수 없어야 합니다.
- 엔드포인트와 파라미터는 `src/validate.js` 화이트리스트로만 허용합니다. 추가할 때는 형식 검증과 시험을 같이 추가합니다.
- 인증은 서버 간 `X-Proxy-Token`입니다. CORS나 Origin을 인증으로 쓰지 않습니다. 브라우저 코드에 토큰을 넣지 않습니다.
- 키·토큰·원 IP·쿼리 값은 로그와 응답에 남기지 않습니다(시험 18번).
- 외부 의존성은 0개를 유지합니다(Node 18+ 내장 모듈만 사용).

## 작업 규칙
- 작업마다 브랜치를 만들고, `npm test`를 통과한 상태로 PR을 엽니다.
- main 병합과 Railway 배포는 사용자 승인 후에만 합니다. 롤백은 README의 절차를 따릅니다.
- 실제 DART 호출 시험에는 실제 키를 쓰지 않습니다. 단위 시험은 `fetchDart`를 주입한 가짜 응답으로 합니다.
